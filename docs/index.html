nf-core meta-omics — the pipeline conveyor

The meta-omics “metro map” sets out how these pipelines could chain together — a roadmap of intended synergy rather than a set of guarantees. This page tracks the work of walking it end to end on real data: what each pipeline needs as input, which handoffs we have exercised so far, and where a bridge is still needed. Bridges become converter scripts and upstream feature requests. A real dataset’s sequencing runs travel the belt as far as the evidence goes — today, one hop.
